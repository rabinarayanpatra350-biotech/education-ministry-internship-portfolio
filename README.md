## The narrative arc

The internship was deliberately built as one continuous story about a single policy domain — foundational literacy and numeracy (FLN) — deepening each week:

1. **Week 1** mapped *how the ministry works* — hierarchy, procedures, law, budget.
2. **Week 2** documented *what the office does* — and its monitoring work surfaced the weakness: PGI learning outcomes 41.2/100.
3. **Week 3** therefore selected the FLN project (via a scored criteria matrix) and applied the *project lifecycle* to it.
4. **Week 4** analysed the *policy* behind that project — its arc, effectiveness, and options.
5. **Week 5** mapped the *people* — the stakeholder ecosystem, consultations, feedback loops, coordination.
6. **Week 6** assembled everything into the *capstone*: **Coimbatore FLN 2027**, a district-level acceleration project, and a competency self-assessment.
